# STM32F103C8T6 参数中文速查

> 随工程自带的中文手册。厂商库（StdPeriph/CMSIS）保持英文原样以便跟随官方升级，
> 你最常用到的参数都在这里翻译好了。配合 F12 跳转定义 + 悬停使用。

## 1. 时钟树（记住三句话）

- 上电默认 **HSE 8MHz 外部晶振 × 9 倍频 = SYSCLK 72MHz**（`system_stm32f10x.c` 自动配好）
- **APB2（72MHz）**：GPIOA~G、USART1、ADC、SPI1、TIM1 —— 高速外设
- **APB1（36MHz，别超）**：USART2/3、SPI2、TIM2~4、I2C —— 低速外设
- 外设没反应先查**时钟开了没**：`RCC_APB2PeriphClockCmd(具体宏, ENABLE);`

## 2. GPIO（点灯/按键三步）

```c
GPIO_InitTypeDef gpio;
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOC, ENABLE);  // 1. 开时钟
gpio.GPIO_Pin   = GPIO_Pin_13;                         // 2. 配引脚
gpio.GPIO_Mode  = GPIO_Mode_Out_PP;                    //    配模式
gpio.GPIO_Speed = GPIO_Speed_2MHz;                     //    配速度
GPIO_Init(GPIOC, &gpio);                               // 3. 生效
GPIO_ResetBits(GPIOC, GPIO_Pin_13);                    // 4. 输出低 = 点亮 PC13
```

### GPIO_Mode 八种模式对照

| 宏 | 中文含义 | 什么时候用 |
|---|---|---|
| `GPIO_Mode_Out_PP` | 推挽输出 | 点灯、驱动数字信号（最常用） |
| `GPIO_Mode_Out_OD` | 开漏输出 | 总线/I2C 类，需外接上拉 |
| `GPIO_Mode_AF_PP` | 复用推挽输出 | **引脚交给外设时必用**：UART TX、PWM 输出 |
| `GPIO_Mode_AF_OD` | 复用开漏 | I2C 的 SDA/SCL |
| `GPIO_Mode_AIN` | 模拟输入 | ADC 采集通道 |
| `GPIO_Mode_IN_FLOATING` | 浮空输入 | 外部信号已确定电平（如 UART RX） |
| `GPIO_Mode_IPU` | 上拉输入 | **按键**（另一脚接地，松开读 1） |
| `GPIO_Mode_IPD` | 下拉输入 | 按键另一脚接 VCC 时 |

### GPIO_Speed：`GPIO_Speed_2MHz / 10MHz / 50MHz`——越快功耗越大，点灯 2MHz 足够。

## 3. USART1 串口（PA9=TX，PA10=RX，交叉接 USB 转串口）

```c
RCC_APB2PeriphClockCmd(RCC_APB2Periph_USART1 | RCC_APB2Periph_GPIOA, ENABLE);
// TX(PA9): GPIO_Mode_AF_PP；RX(PA10): GPIO_Mode_IN_FLOATING
USART_InitTypeDef u;
u.USART_BaudRate   = 115200;                  // 波特率
u.USART_WordLength = USART_WordLength_8b;     // 8 位数据
u.USART_StopBits   = USART_StopBits_1;       // 1 位停止
u.USART_Parity     = USART_Parity_No;        // 无校验
u.USART_Mode       = USART_Mode_Rx | USART_Mode_Tx;  // 收发都开
u.USART_HardwareFlowControl = USART_HardwareFlowControl_None;  // 无流控
USART_Init(USART1, &u);
USART_Cmd(USART1, ENABLE);
USART_SendData(USART1, 'A');                  // 发送：写 SBUF
while (USART_GetFlagStatus(USART1, USART_FLAG_TXE) == RESET);  // 等发送寄存器空
```

## 4. 常用 StdPeriph 函数签名（中文参数）

| 函数 | 参数说明 |
|---|---|
| `RCC_APB2PeriphClockCmd(宏, ENABLE)` | 宏=`RCC_APB2Periph_GPIOA/B/C…、USART1、ADC1、SPI1、TIM1` |
| `RCC_APB1PeriphClockCmd(宏, ENABLE)` | 宏=`RCC_APB1Periph_USART2/3、TIM2/3/4、SPI2、I2C1/2` |
| `GPIO_SetBits(端口, 引脚)` | 输出高；`GPIO_ResetBits` 输出低；`GPIO_ReadOutputDataBit` 读输出 |
| `GPIO_ReadInputDataBit(端口, 引脚)` | 读引脚实际电平（按键/输入用这个） |
| `GPIO_Write(端口, 0xXXXX)` | 整组 16 位一次写 |
| `TIM_SetCompare2(TIM3, 值)` | 改 PWM 比较值（占空比）；TIM3 PWM 常用 PA6~PA7/PB0~PB1 |
| `NVIC_Init(&nvic)` | 中断优先级结构体：`NVIC_IRQChannel` 选中断号，`NVIC_IRQChannelPreemptionPriority` 抢占优先级，`NVIC_IRQChannelSubPriority` 子优先级，`NVIC_IRQChannelCmd` ENABLE |

## 5. 中断写法（标准库 + 启动文件 startup_stm32f10x_md.s）

中断服务函数名**必须和启动文件里一致**（覆写弱符号），常用的：

| 函数名 | 对应中断 |
|---|---|
| `USART1_IRQHandler` | 串口1 收发 |
| `TIM2_IRQHandler` / `TIM3_IRQHandler` | 定时器 2/3 |
| `EXTI0_IRQHandler` … `EXTI15_10_IRQHandler` | 外部中断（PC13 按键类是 EXTI15_10） |

中断里取数据后记得**清标志**（标准库多数读/操作即清，EXTI 要 `EXTI_ClearITPendingBit`）。

## 6. 新手常见坑

1. **HSE 起振失败卡死**：`system_stm32f10x.c` 等 8M 晶振起振——板上必须有 8M 晶振（Blue Pill 有）。
2. **忘了开时钟**：外设寄存器写不进去（读恒 0），第一反应查 RCC。
3. **PA9/PA10 被占用**：串口烧录/系统bootloader 用它们，跳线别冲突。
4. **PC13 驱动能力弱**：官方限制 PC13~15 只能带 3mA 左右，只够板载 LED，别驱动继电器。
5. **APB1 外设用了 72MHz 的时钟宏**：USART2 挂 APB1，要 `RCC_APB1PeriphClockCmd`。
